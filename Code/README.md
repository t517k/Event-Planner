# Event Planner README

The even planner program demonstrates the difference between brute force and dynamic programming methods to achieve the same result.
[Github repository](https://github.com/t517k/Event-Planner)

The zip file should include all files related to running the program and all required documents in their respective folders.  
The following features are included:

- Brute force algorithm
- Dynamic algorithm
- Greedy heuristics addon
- Formatted output

## Running Instructions

The brute force and dynamic methods are both run together using the same file.  
There are two ways that the program can be run.  
Select one of the following and follow the instructions.

### Build from source

1. Download the zip file of the event planner from the github repository or use zip provided through ele
2. Open the downloaded zip and extract the folder "Event-Planner-main" to a convenient location on the device
3. Open the Event-Planner-main folder with an IDE of choice
4. Navigate to the Code folder and then to event_planner.py
5. Select event_planner.py and ensure a python kernel is selected
6. Run the file - The output is placed in the main folder
7. Open and observe output.txt for results of both the brute force and dynamic methods

### Run from terminal

1. Download the zip file of the event planner from the github repository or use zip provided through ele
2. Open the downloaded zip and extract the folder "Event-Planner-main" to a convenient location on the device
3. Open a terminal instance inside Event-Planner-main
4. Check python is present and installed with `python --version` in the termial
5. Once confirmed, use `python Code/event_planner.py` in the terminal
6. Output is placed in the main folder
7. Open and observe output.txt for results of both the brute force and dynamic methods

## Dependencies

- Python version `3.12.4` or higher
- File structure in order
- An IDE of user's choice
